# 人物记忆库（SillyTavern 第三方扩展）

一个**非剧情向**的记忆存储插件：自动从聊天中提取**人物特征、物品特征、环境特征、社会结构**，并按可自定义的规则注入到提示词中。专为手机端设计：可拖拽悬浮球 + 半屏抽屉面板。

---

## 一、功能总览

| 模块 | 内容 |
| --- | --- |
| 人物 | 外貌（只增不改＋AI 建议修改待确认）、天赋（性格/资质）、技能（招式/法术）、关系网、财产（物品与生物）、情绪与健康状态（实时覆盖）、外表状态（穿着首饰，实时覆盖）、自定义字段 |
| 物品 | 简略描述、功能特性、归属、完整度（损毁/残缺…） |
| 环境 | 概况、布局变化（新增建筑/家具/破坏/损毁，累积记录） |
| 社会结构 | 势力、宗教、组织、单位、社交圈等 |
| 自定义 | 自建一级类目，条目含 名称 / 注入规则 / 内容，AI 也会自动提取填充 |
| 报错栏 | 提取失败 / API 报错 / 解析失败，保留最近 20 条，一键复制、重试提取 |
| 统计 | 条目数量、注入字符数、提取次数等（简化版） |

## 二、安装

1. 解压后得到文件夹 `st-character-memory`。
2. 把整个文件夹放到 SillyTavern 的：
   ```
   SillyTavern/public/scripts/extensions/third-party/st-character-memory
   ```
   （手机 Termux 部署的酒馆路径相同；用 MT 管理器 / 文件管理器拷贝即可）
3. 重启 SillyTavern 服务（或刷新页面），在「扩展」面板中确认「人物记忆库」已启用。
4. 聊天界面右下角会出现一个圆形悬浮球，点开即是记忆面板。

> 支持 SillyTavern 1.10+（使用了第三方扩展标准接口）。文件夹名不要随意改动。

## 三、使用说明

### 提取
- **自动提取**：默认每 6 楼一次（可在设置中改）。每次提取合并最近 N 楼（默认 6，可改），自动追赶未提取的楼层。
- **立即提取**：面板顶部按钮，立刻对当前未提取楼层跑一次。
- **历史回填**：设置页按钮，把当前聊天从第 1 楼开始分批跑一遍，建立初始档案；可随时取消。
- **重新生成（swipe）**：撤回机制——对被 swipe 的楼层，自动恢复到提取前的档案状态，并把该楼标记回"未提取"，最终以采用的那条回复为准重新提取。
- **副 API**：设置里开启后，提取走你配置的 OpenAI 兼容接口（便宜小模型即可），不影响主对话；不开启则走主对话同一个 API（静默生成）。
  - ⚠️ 副 API 直接从浏览器请求，接口需允许跨域（CORS）。官方 OpenAI / DeepSeek / 通义兼容端点一般可以；自建反代请在响应头加 `Access-Control-Allow-Origin`。

### 存储
- 默认**按聊天隔离**（存在该聊天的 metadata 里，换聊天互不干扰）。
- 设置里打开「全局库」后，所有聊天共用同一份档案。
- 全部为**本地存储**，不上传任何服务器（提取内容只会发给你自己配置的 API）。
- 支持导出 / 导入 JSON 备份。

### 注入规则
- 每个一级类目（人物/物品/环境/社会结构/自定义类目）都有独立注入规则：**开关、模式（全量 / 关键词触发 / 最近提及）、关键词、注入深度**。
- 每个条目（含自定义新增条目）还可以再覆盖自己的规则。
- **全量**：每次都注入该类目全部内容（默认）。
- **最近提及**：条目名称或关键词出现在最近 K 楼（默认 10）才注入——省 token。
- **关键词**：仅当关键词命中最近 K 楼才注入。
- 自定义条目规则结构相同。

### 状态类字段的更新策略
- 「情绪与健康状态」「外表状态」：**每次提取整体覆盖**（实时刷新）。
- 外貌 / 天赋 / 技能 / 关系 / 财产 / 布局：**累积制**，只增不改。
- 外貌例外：剧情出现剪发、留疤等不可逆变化时，AI 不会直接改旧描述，而是生成一条「建议修改」，在人物详情页由你**确认替换或忽略**。

## 五、常见问题

- **悬浮球挡住输入框**：按住拖动即可，位置会记住。
- **提取没反应**：看「报错」页。常见原因是主 API 正在生成中、或副 API 跨域/密钥错误。
- **注入没生效**：设置页确认「注入总开关」打开，且对应类目规则为启用；模式为「最近提及/关键词」时不命中是不会注入的。
- **数据在哪**：按聊天隔离时藏在聊天文件 metadata 中；「导出数据」可拿到完整 JSON。
